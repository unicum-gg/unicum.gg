## Unterstützerzahlungen

{name} wird von seinen Spielern finanziert. Auf der [Support-Seite]({support-page}) können Sie einen beliebigen Betrag zahlen, entweder **einmalig** oder **monatlich**, jeweils ab dem dort angezeigten Mindestbetrag. Die Preise sind in Euro angegeben und Endpreise: Es wird keine Mehrwertsteuer hinzugefügt.

Eine monatliche Unterstützung verleiht Ihnen ein Unterstützerabzeichen in Ihrem Profil, die Unterstützerrolle auf unserem Discord-Server, einen Platz auf der Unterstützertafel und Zugriff auf die Einstellungen nur für Unterstützer. Nichts anderes auf der Website ist jemals davon abhängig. Eine einmalige Zahlung zählt für die Unterstützertafel.

Zahlungen werden von Stripe verarbeitet. Eine monatliche Unterstützung verlängert sich jeden Monat automatisch, bis Sie sie kündigen. Dies können Sie jederzeit in Ihren Kontoeinstellungen über „Manage subscription“ tun. Sie bleibt anschließend bis zum Ende des bereits bezahlten Monats aktiv und wird nicht erneut berechnet.

**Widerrufsrecht.** Sie haben ab Ihrer ersten Zahlung 14 Tage Zeit, es sich anders zu überlegen, ohne einen Grund anzugeben. Schreiben Sie innerhalb dieses Zeitraums an [{email}](mailto:{email}). Die Zahlung wird innerhalb von 14 Tagen nach Ihrem Antrag vollständig und über dasselbe Zahlungsmittel erstattet.

**Streitigkeiten.** Falls bei einer Zahlung etwas schiefgeht, schreiben Sie uns zunächst. Wenn wir die Angelegenheit nicht gemeinsam beilegen können, können Sie sie kostenlos einem Verbraucherschlichter vorlegen, wie im [Impressum]({company-page}) beschrieben.
