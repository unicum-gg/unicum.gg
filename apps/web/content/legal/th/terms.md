## เกี่ยวกับข้อกำหนดนี้

ข้อกำหนดนี้ใช้บังคับกับการใช้ {name} ของคุณ ซึ่งเผยแพร่โดย {publisher} (ดู [ประกาศทางกฎหมาย]({company-page})) การใช้เว็บไซต์ API บอต Discord หรือม็อดเกม ถือว่าคุณยอมรับข้อกำหนดนี้ หากไม่ยอมรับ โปรดอย่าใช้บริการ

## บริการ

{name} เผยแพร่สถิติฟรีเกี่ยวกับผู้เล่น แคลน ยานพาหนะ แผนที่ และเซิร์ฟเวอร์ของ World of Tanks โดยจัดทำจากข้อมูลที่ Wargaming เปิดเผยต่อสาธารณะผ่าน API อย่างเป็นทางการ และจากการรบที่ผู้เล่นเลือกแชร์ผ่าน [ม็อดเกม]({mod-page})

{name} เป็นโครงการอิสระ **ไม่มีความเกี่ยวข้อง ไม่ได้รับการรับรอง หรือได้รับการสนับสนุนจาก Wargaming** และ World of Tanks รวมถึงเนื้อหาของเกมเป็นของ Wargaming.net

บริการนี้ให้ใช้งานโดยไม่คิดค่าใช้จ่ายตามสภาพที่เป็นอยู่ และอาจมีการเปลี่ยนแปลง หยุดชั่วคราว หรือยุติได้ทุกเมื่อ เราพยายามอย่างเต็มที่เพื่อให้บริการมีความถูกต้องและพร้อมใช้งาน แต่เราไม่สามารถรับประกันสิ่งใดสิ่งหนึ่งได้

## ข้อมูลจาก Wargaming และผู้เล่น

สถิติที่แสดงคำนวณจากข้อมูลที่ Wargaming จัดหาให้ และอาจไม่ครบถ้วน ล่าช้า หรือไม่ถูกต้อง การจัดอันดับและตัวเลขที่คำนวณขึ้นเป็นค่าประมาณ ไม่ใช่ผลอย่างเป็นทางการ

ชื่อเล่น ชื่อแคลน แท็ก คำอธิบายแคลน และลิงก์ใด ๆ ที่มีอยู่ในนั้น เขียนโดยผู้เล่นของ Wargaming และนำมาเผยแพร่ซ้ำตามที่ Wargaming จัดหาให้ {name} ไม่ได้เป็นผู้เขียน ตรวจสอบ หรือรับรองเนื้อหาเหล่านั้น และไม่รับผิดชอบต่อข้อความดังกล่าว หากต้องการรายงานเนื้อหาใด ให้ใช้เครื่องมือรายงานของ Wargaming เอง โดยสิ่งที่ Wargaming เปลี่ยนแปลงหรือลบจะได้รับการอัปเดตที่นี่ในครั้งถัดไปที่เราอ่านข้อมูล

## บัญชีของคุณ

คุณเข้าสู่ระบบด้วย Wargaming.net ID และรับผิดชอบต่อการดำเนินการใด ๆ ที่เกิดขึ้นกับบัญชีของคุณ เราอาจระงับหรือปิดบัญชีที่ใช้เพื่อใช้บริการ ผู้ใช้บริการ หรือโครงสร้างพื้นฐานในทางที่ไม่เหมาะสม

## สิ่งที่คุณเผยแพร่

เมื่อคุณให้คะแนนยานพาหนะหรือแผนที่ เขียนรีวิว หรือส่งวิดีโอ คุณยังคงเป็นผู้เขียน และมอบใบอนุญาตใช้งานโดยไม่คิดค่าใช้จ่ายและใช้ได้ทั่วโลกแก่ {name} เพื่อแสดงเนื้อหาดังกล่าวบนเว็บไซต์และการเชื่อมต่อกับบริการอื่นของเว็บไซต์ ตราบเท่าที่เนื้อหานั้นยังเผยแพร่บนเว็บไซต์

คุณตกลงว่าจะไม่เผยแพร่สิ่งใดที่ผิดกฎหมาย เป็นการดูหมิ่น แสดงความเกลียดชัง ทำให้เข้าใจผิด หรือละเมิดสิทธิของผู้อื่น เนื้อหาที่ส่งเข้ามาจะได้รับการกลั่นกรอง เราอาจปฏิเสธ แก้ไข หรือลบเนื้อหาใด ๆ และคุณสามารถถอนเนื้อหาของคุณได้ทุกเมื่อ

## API บอต และม็อดเกม

API สาธารณะ บอต Discord และม็อดเกมสามารถใช้งานได้ฟรีภายในขอบเขตที่สมเหตุสมผล ห้ามทำให้บริการมีภาระเกินควร หลีกเลี่ยงข้อจำกัดอัตราการใช้งาน หรือดึงข้อมูลในลักษณะที่ทำให้บริการเสื่อมประสิทธิภาพสำหรับผู้อื่น เราอาจบล็อกไคลเอ็นต์ใด ๆ ที่ดำเนินการดังกล่าว

คุณติดตั้งม็อดเกมโดยยอมรับความเสี่ยงเอง ม็อดจะอ่านเฉพาะสิ่งที่ไคลเอ็นต์เกมแสดงให้คุณเห็นและส่งข้อมูลนั้นไปยัง {name} และแต่ละเวอร์ชันจะได้รับการตรวจสอบโดย Wargaming ก่อนปรากฏบนศูนย์รวมม็อดของ Wargaming

## การชำระเงินของผู้สนับสนุน

{name} ได้รับเงินทุนจากผู้เล่น ที่ [หน้าสนับสนุน]({support-page}) คุณสามารถชำระเงินตามจำนวนที่ต้องการได้ทั้งแบบ **ครั้งเดียว** หรือ **ทุกเดือน** โดยเริ่มจากจำนวนขั้นต่ำที่แสดงไว้ที่นั่น ราคาเป็นสกุลเงินยูโรและเป็นราคาสุทธิ ไม่มีการเรียกเก็บภาษีมูลค่าเพิ่มเพิ่มเติม

การสนับสนุนรายเดือนจะมอบป้ายผู้สนับสนุนบนโปรไฟล์ของคุณ บทบาทผู้สนับสนุนบนเซิร์ฟเวอร์ Discord ของเรา พื้นที่บนกระดานผู้สนับสนุน และการตั้งค่าสำหรับผู้สนับสนุนเท่านั้น ไม่มีสิ่งอื่นใดบนเว็บไซต์ที่ถูกจำกัดการเข้าถึงด้วยเหตุนี้ การชำระเงินครั้งเดียวจะนับรวมในกระดานผู้สนับสนุน

Stripe เป็นผู้ดำเนินการชำระเงิน การสนับสนุนรายเดือนจะต่ออายุโดยอัตโนมัติทุกเดือนจนกว่าคุณจะยกเลิก ซึ่งคุณสามารถทำได้ทุกเมื่อจากการตั้งค่าบัญชี โดยเลือก “Manage subscription” จากนั้นการสนับสนุนจะยังคงใช้งานได้จนถึงสิ้นเดือนที่ชำระเงินไว้แล้ว และจะไม่มีการเรียกเก็บเงินอีก

**สิทธิในการถอนตัว** คุณมีเวลา 14 วันนับจากการชำระเงินครั้งแรกเพื่อเปลี่ยนใจโดยไม่ต้องให้เหตุผล โปรดเขียนถึงเราที่ [{email}](mailto:{email}) ภายในระยะเวลาดังกล่าว แล้วเราจะคืนเงินเต็มจำนวนด้วยวิธีการเดียวกันภายใน 14 วันนับจากวันที่ได้รับคำขอของคุณ

**ข้อพิพาท** หากเกิดปัญหากับการชำระเงิน โปรดเขียนถึงเราก่อน หากเราไม่สามารถยุติเรื่องร่วมกันได้ คุณอาจส่งเรื่องไปยังผู้ไกล่เกลี่ยข้อพิพาทผู้บริโภคได้โดยไม่เสียค่าใช้จ่าย ตามที่ระบุไว้ใน [ประกาศทางกฎหมาย]({company-page})

## ทรัพย์สินทางปัญญา

การออกแบบ ข้อความ และโค้ดของ {name} เป็นของเรา โค้ดดังกล่าวเป็นโอเพนซอร์สภายใต้ GNU Affero General Public License v3 และข้อกำหนดของใบอนุญาตนี้มีผลกับทุกคนที่นำโค้ดไปใช้ซ้ำ เนื้อหาของ World of Tanks เป็นของ Wargaming.net

## ความรับผิด

{name} ไม่รับผิดชอบต่อความเสียหายทางอ้อม การตัดสินใจที่เกิดขึ้นจากสถิติของบริการ หรือการหยุดชะงักของบริการ ไม่มีข้อความใดในข้อกำหนดนี้จำกัดสิทธิที่กฎหมายคุ้มครองผู้บริโภคของฝรั่งเศสมอบให้คุณ

## การเปลี่ยนแปลงและกฎหมายที่ใช้บังคับ

ข้อกำหนดนี้อาจมีการเปลี่ยนแปลง วันที่ด้านบนของหน้าระบุวันที่มีการเปลี่ยนแปลงครั้งล่าสุด และการใช้บริการต่อไปถือว่าคุณยอมรับฉบับปัจจุบัน

ข้อกำหนดนี้อยู่ภายใต้กฎหมายฝรั่งเศส ข้อพิพาทใด ๆ ที่ไม่สามารถยุติฉันมิตรได้จะถูกนำขึ้นสู่ศาลฝรั่งเศสที่มีเขตอำนาจ โดยไม่กระทบต่อสิทธิของผู้บริโภคในการฟ้องคดีต่อศาลในประเทศของตนเอง
