## ผู้รับผิดชอบ

ผู้ควบคุมข้อมูลคือ {publisher} ผู้เผยแพร่ {name} โดยมีรายละเอียดอยู่ใน[ประกาศทางกฎหมาย]({company-page}) คำถามทุกข้อเกี่ยวกับข้อมูลของคุณส่งไปที่ [{email}](mailto:{email})

## ข้อมูล World of Tanks

ข้อมูลส่วนใหญ่ที่ {name} แสดงไม่ได้เก็บรวบรวมจากคุณ แต่เป็นข้อมูลสาธารณะที่ Wargaming เผยแพร่เกี่ยวกับทุกบัญชีและแคลนผ่าน API อย่างเป็นทางการ ซึ่งเราอ่าน จัดเก็บ และนำมาคำนวณ ได้แก่:

- ชื่อเล่นของบัญชี แคลน สถิติการรบ ยานพาหนะ เหรียญรางวัล และค่าจัดอันดับ รวมถึงชื่อแคลน แท็ก สมาชิก คำอธิบาย และผลการแข่งขันของแคลน
- การเปลี่ยนแปลงของตัวเลขเหล่านั้นตามช่วงเวลา รวมถึงชื่อเล่นและแคลนในอดีต ซึ่งทำให้เว็บไซต์แสดงความก้าวหน้าและประวัติได้
- สำหรับผู้เล่นที่เชื่อมโยงช่อง Twitch สถานะว่าช่องนั้นกำลังถ่ายทอดสดอยู่หรือไม่

เราประมวลผลข้อมูลโดยอาศัย**ประโยชน์โดยชอบด้วยกฎหมาย**ของเราในการเผยแพร่สถิติเกี่ยวกับเกมสาธารณะ ซึ่งเป็นข้อมูลเดียวกับที่ Wargaming แสดงเอง การจัดการบัญชีของคุณโดย Wargaming อธิบายไว้ใน[นโยบายความเป็นส่วนตัว]({wargaming-policy})ของ Wargaming

## บัญชีของคุณ

การเข้าสู่ระบบเป็นทางเลือก และทำได้ผ่าน Wargaming.net ID เท่านั้น คุณพิมพ์รหัสผ่านในหน้าของ Wargaming เอง และรหัสผ่านจะไม่มาถึงเรา เมื่อคุณเข้าสู่ระบบ เราจะเก็บข้อมูลดังต่อไปนี้:

- ID บัญชี Wargaming ชื่อเล่น และภูมิภาคของคุณ รวมถึงโทเค็นการเข้าถึงที่ Wargaming ส่งกลับมา ซึ่งเข้ารหัสขณะจัดเก็บ และทำให้เราอ่านข้อมูลบัญชีของคุณเองและดำเนินการแทนคุณได้เฉพาะในส่วนที่คุณตั้งค่าไว้
- คุกกี้เซสชัน พร้อมที่อยู่ IP และเบราว์เซอร์ที่เปิดเซสชันนั้น เพื่อให้เซสชันเป็นของคุณ
- บัญชี Twitch หรือ Discord ที่คุณเลือกเชื่อมต่อ โดยระบุด้วย ID และชื่อผู้ใช้ ซึ่งคุณสามารถยกเลิกการเชื่อมต่อได้ทุกเมื่อจากการตั้งค่าของคุณ

เราประมวลผลข้อมูลนี้เพื่อ**ให้บริการที่คุณร้องขอ** ได้แก่ บัญชี การตั้งค่า และการเชื่อมต่อของบัญชี

## ม็อดเกม

[ม็อดเกม]({mod-page}) ซึ่งเป็นทางเลือก จะส่งข้อมูลสิ่งที่เกิดขึ้นในการรบที่คุณเล่นขณะติดตั้งม็อดดังกล่าวมาให้เรา:

- ผลการรบที่ตัวเกมแสดงหลังการรบ ซึ่งระบุชื่อผู้เข้าร่วมทุกคน ทำให้การรบนั้นปรากฏในโปรไฟล์ของผู้เล่นที่ไม่เคยติดตั้งม็อดได้
- อุปกรณ์ ยุทโธปกรณ์ กระสุน การปรับแต่งภาคสนาม และทักษะพลรถที่ติดตั้งสำหรับการรบแต่ละครั้ง
- โทเค็นที่เชื่อมโยงม็อดกับบัญชีของคุณ ซึ่งจัดเก็บในรูปแฮชเท่านั้น

จากการตั้งค่าของคุณ คุณสามารถซ่อนรายการการรบไม่ให้ใครเห็นนอกจากคุณเอง และนำชุดอุปกรณ์ของคุณออกจากตารางที่ระบุชื่อผู้เล่นได้ ชุดอุปกรณ์ที่ซ่อนไว้ยังคงถูกนับโดยไม่เปิดเผยตัวตนในตัวเลขของยานพาหนะแต่ละคัน

## สิ่งที่คุณเผยแพร่

ฟีเจอร์บางอย่างมีไว้เพื่อเผยแพร่สิ่งที่คุณเขียน และจะได้รับการตรวจสอบโดยผู้ดูแลก่อน:

- การจัดอันดับและรีวิวเป็นลายลักษณ์อักษรเกี่ยวกับยานพาหนะและแผนที่ของคุณ ซึ่งจะแสดงพร้อมชื่อเล่นของคุณเมื่อได้รับอนุมัติ
- วิดีโอที่คุณส่ง พร้อมรายละเอียดการรบที่คุณให้ไว้
- ข้อความที่ส่งผ่านแบบฟอร์มความคิดเห็น พร้อมชื่อเล่นของคุณเมื่อคุณเข้าสู่ระบบ ซึ่งจะส่งไปยังช่อง Discord ส่วนตัว

## การชำระเงินของผู้สนับสนุน

การชำระเงินใน[หน้าสนับสนุน]({support-page})ดำเนินการโดย Stripe ทั้งหมด คุณพิมพ์รายละเอียดบัตรในหน้าของ Stripe และรายละเอียดดังกล่าวจะไม่มาถึงเรา ดู[นโยบายความเป็นส่วนตัวของ Stripe]({stripe-policy})

เราเก็บรหัสลูกค้า Stripe ของคุณ จำนวนเงิน สกุลเงิน วันที่ และสถานะของการชำระเงินแต่ละครั้ง รวมถึงสถานะว่าการสนับสนุนรายเดือนยังใช้งานอยู่หรือไม่ เพื่อให้ป้ายผู้สนับสนุนและบทบาท Discord ของคุณสอดคล้องกับข้อมูลดังกล่าว เราเก็บบันทึกทางบัญชีไว้ตามระยะเวลาที่กฎหมายฝรั่งเศสกำหนด

ผู้สนับสนุนจะปรากฏบนกระดานผู้สนับสนุนสาธารณะพร้อมชื่อเล่นและยอดรวมของตน คุณสามารถเลือกซ่อนตัวจากกระดานดังกล่าวได้ในการตั้งค่าของคุณ

## คุกกี้และพื้นที่จัดเก็บในเครื่อง

{name} จัดเก็บข้อมูลบางอย่างไว้ในเบราว์เซอร์ของคุณ:

- **จำเป็น:** คุกกี้เซสชัน และคุกกี้อายุสั้นที่ช่วยปกป้องการเข้าสู่ระบบและการเชื่อมต่อบัญชี ซึ่งฟีเจอร์เหล่านี้ไม่สามารถทำงานได้หากไม่มีคุกกี้ดังกล่าว
- **การตั้งค่า:** ภูมิภาค ภาษา เมตริกการจัดอันดับ ตัวเลือกการแสดงผล และการค้นหาล่าสุดของคุณ ซึ่งจัดเก็บไว้เพื่อให้เว็บไซต์เปิดในแบบที่คุณใช้งานครั้งล่าสุด
- **การวัดกลุ่มผู้เข้าชม:** Umami ซึ่งนับจำนวนการเข้าชมโดยไม่ใช้คุกกี้และไม่ระบุตัวตนของคุณ
- **การวิเคราะห์:** Google Analytics 4 ซึ่งตั้งค่าคุกกี้และ**จะโหลดก็ต่อเมื่อคุณยอมรับเท่านั้น**ในแบนเนอร์คุกกี้

คุณสามารถเปลี่ยนตัวเลือกของคุณได้ทุกเมื่อโดยเลือก “จัดการคุกกี้” ที่ด้านล่างของทุกหน้า

## ผู้ที่จัดการข้อมูลนี้รายอื่น

เราไม่ขายข้อมูลของคุณ และไม่มีโฆษณา ผู้ให้บริการเหล่านี้จัดการข้อมูลบางส่วนแทนเรา โดยแต่ละรายอยู่ภายใต้นโยบายของตนเอง:

- **netcup** (เยอรมนี): ให้บริการโฮสต์เว็บไซต์ ฐานข้อมูล และ API
- **Cloudflare**: ให้บริการส่งและปกป้องเว็บไซต์ โดยเห็นทุกคำขอ [นโยบาย]({cloudflare-policy})
- **Wargaming**: การเข้าสู่ระบบและข้อมูลเกม [นโยบาย]({wargaming-policy})
- **Stripe**: การชำระเงิน [นโยบาย]({stripe-policy})
- **Discord**: การดูแลรีวิวและวิดีโอ ความคิดเห็น และบทบาทผู้สนับสนุน [นโยบาย]({discord-policy})
- **Twitch**: สถานะการถ่ายทอดสดของช่องที่เชื่อมโยง [นโยบาย]({twitch-policy})
- **Umami** (โฮสต์ในสหภาพยุโรป): การวัดกลุ่มผู้เข้าชม [นโยบาย]({umami-policy})
- **Google**: Google Analytics 4 โดยใช้เฉพาะเมื่อคุณให้ความยินยอม [นโยบาย]({google-policy})

ผู้ให้บริการบางรายตั้งอยู่ในสหรัฐอเมริกา การโอนข้อมูลไปยังที่นั่นอาศัยมาตรการคุ้มครองที่ RGPD กำหนดไว้ เช่น กรอบการคุ้มครองข้อมูล EU-US หรือข้อสัญญามาตรฐานของคณะกรรมาธิการยุโรป

## เราเก็บข้อมูลไว้นานเท่าใด

- **ข้อมูล World of Tanks:** เป็นส่วนหนึ่งของประวัติสถิติ ตราบเท่าที่เว็บไซต์เผยแพร่ข้อมูลดังกล่าว
- **บัญชีและการเชื่อมต่อ:** จนกว่าคุณจะขอให้เราลบบัญชีของคุณ
- **เซสชัน:** จนกว่าคุณจะออกจากระบบหรือเซสชันหมดอายุ
- **บันทึกการชำระเงิน:** ตามระยะเวลาที่กฎหมายบัญชีของฝรั่งเศสกำหนด
- **การจัดอันดับ รีวิว และวิดีโอ:** ตราบเท่าที่มีการเผยแพร่ หรือจนกว่าคุณจะถอนข้อมูลดังกล่าว
- **บันทึกเซิร์ฟเวอร์:** ไม่เกินสองสามวัน

## สิทธิของคุณ

ภายใต้ RGPD คุณสามารถขอเข้าถึงข้อมูลที่เราเก็บเกี่ยวกับคุณ ขอให้แก้ไข ลบ จำกัดหรือคัดค้านการประมวลผล และขอรับข้อมูลในรูปแบบที่ถ่ายโอนได้ หากการประมวลผลอาศัยความยินยอมของคุณ คุณสามารถถอนความยินยอมได้ทุกเมื่อ

เขียนถึง [{email}](mailto:{email}) จากที่อยู่ที่เราสามารถตอบกลับได้ และแจ้งให้เราทราบว่าคำขอนั้นเกี่ยวข้องกับบัญชีใด เราจะตอบกลับภายในหนึ่งเดือน

เรายินดีแก้ไขข้อสงสัยเกี่ยวกับข้อมูลของคุณโดยตรง นอกจากนี้ คุณยังมีสิทธิติดต่อหน่วยงานคุ้มครองข้อมูลของฝรั่งเศส ซึ่งก็คือ [CNIL]({cnil})

## การเปลี่ยนแปลง

นโยบายนี้จะเปลี่ยนแปลงเมื่อเว็บไซต์เปลี่ยนแปลง วันที่ด้านบนของหน้าจะแจ้งว่านโยบายมีการเปลี่ยนแปลงครั้งล่าสุดเมื่อใด
