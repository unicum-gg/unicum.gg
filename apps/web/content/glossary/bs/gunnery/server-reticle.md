Drugi krstasti ciljnik prikazuje gdje server misli da se puška usmjerava, što je ono protiv čega se stvarno rešava hitac.

Klijent odmah crta krug za cilj, dok server odlučuje kuda projektil ide. Kašnjenje u mreži stavlja oboje malo odvojeno, i na daljini ta razlika je šira od slabog mesta.

Uključivanje server reticle također prikazuje autoritativnu poziciju. Igrači koji snajpere pucaju na server crosshair umjesto na klijentski, što je razlog zašto je to bio mod dugo prije nego što je postalo postavka.
