Den korta fördröjningen mellan två projektiler i samma magasin, som avgör hur snabbt ett burst levereras.

Mellan två skott från ett magasin väntar kanonen ut intra-clip omladdningen, typiskt två till fyra sekunder. Det avgör om ett burst träffar innan målet kan dra sig tillbaka ur sikte eller efter.

Korta intra-clip tider gör ett magasin dödligt mot exponerade mål, långa gör det till en serie riktade skott som motståndaren kan reagera på.
