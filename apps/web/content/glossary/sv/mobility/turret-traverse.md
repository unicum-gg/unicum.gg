Hur snabbt tornet roterar, i grader per sekund, oberoende av marken som fordonet står på.

Turret traverse avgör hur snabbt ett vapen kan riktas mot ett mål som dyker upp från en oväntad riktning, och om ett fordon kan spåra en snabb motståndare utan att vrida sin skrov.

Det har ett pris: att vrida tornet vidgar siktcirkeln, så ett långsamt torn och kraftig tornblom tillsammans gör ett vapen som alltid är ett ögonblick efter.
