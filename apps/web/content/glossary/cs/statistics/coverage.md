Jak velkou část hráčské základny serveru statistický web skutečně sleduje a jak aktuální údaje o těchto účtech má.

Žádný statistický web nesleduje všechny účty. API společnosti Wargaming omezuje počet požadavků, takže web vyhledává účty prostřednictvím seznamů členů klanů a vyhledávání a poté každý z nich aktualizuje v intervalech, které si může dovolit. Pokrytí udává podíl aktivních hráčů v regionu, které má web ve své databázi, a dobu od poslední aktualizace každého účtu.

Je to důležité, protože každý žebříček a každý průměr serveru se počítá ze sledované populace, nikoli z celého serveru. Široké pokrytí znamená, že jsou tato čísla reprezentativní, zatímco při malém pokrytí představují pouze vzorek.
