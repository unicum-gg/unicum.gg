Drugi ciljač koji pokazuje gdje server misli da je pištolj usmjeren, što je ono protiv čega se ispaljuje hitac.

Klijent odmah crta ciljnu točku, server odlučuje gdje projektil ide. Kašnjenje u mreži malo razdvaja to dvoje, a na većim udaljenostima ta razlika je šira od slabog mjesta.

Uključivanje server cilja također crta autoritativnu poziciju. Igrači koji snajperiraju pucaju na server cilja umjesto na klijentski, zbog čega je bio mod dugo prije nego što je postao opcija.
