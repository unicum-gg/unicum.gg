전투량을 단순히 자격 기준으로만 적용하지 않고 보상하는 요새 레이팅으로, 수백 회의 전투에서 실력을 입증한 클랜이 20회의 전투에서 동일한 SR을 기록한 클랜보다 높은 순위를 차지합니다.

SR은 의도적으로 클랜의 전투 횟수를 고려하지 않습니다. SRB는 동일한 레이팅에 누적 전투 횟수에 따라 증가하는 항을 곱하므로, 기반이 되는 SR보다 항상 높습니다.

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

로그 방식이므로 첫 100회의 전투는 1000번째 전투보다 훨씬 가치가 큽니다. ```

의도적으로 모든 단계에 동일한 전투량 상수를 적용합니다. 10단계 쟁탈전은 계속 진행되는 반면 원정은 1년에 몇 주 동안 집중적으로 진행되므로, 실제로 더 많이 플레이되는 단계가 더 큰 보너스를 받습니다. 전투량 보너스는 수백 회의 전투에서 레이팅을 유지한 클랜과 20회의 전투 만에 해당 레이팅에 도달한 클랜을 구분하는 요소입니다.
