Drugi prikaz ciljnika koji pokazuje gde server misli da je top usmeren, što je ono protiv čega se zapravo rešava hitac.

Klijent odmah crta krug cilja, server odlučuje gde ide granata. Kašnjenje na mreži stavlja ta dva prikaza malo dalje jedno od drugog, a na daljini je taj razmak širi od slabe tačke.

Uključivanje server ciljnika takođe prikazuje autoritativnu poziciju. Igrači koji snajpuju gađaju server ciljnika umesto klijentskog, zbog čega je to bio mod mnogo pre nego što je postao opcija.
