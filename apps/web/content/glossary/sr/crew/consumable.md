Jednokratna stavka koja se nosi u bitku: popravni setovi, setovi za prvu pomoć, vatrogasni aparati i hrana koja povećava efikasnost cele posade.

Potrošna sredstva su hitni alat. Popravni set popravlja slomljen modul, set za prvu pomoć leči povređenog člana posade, a vatrogasni aparat gasi vatru. Njihove unapređene verzije mogu se koristiti više puta i rade automatski.

Četvrti slot obično sadrži hranu ili piće, što povećava efikasnost svakog člana posade tokom cele bitke, uz cenu gubitka ako se vozilo zapali i troši kredite svaki put kada se koristi.
