一门炮在持续交火中造成的伤害量， alpha 乘以它能发射的频率。

DPM 是 alpha 的持续对应值。它回答了如果一门炮不停开火，它能产生多少伤害，这决定了在双方车辆在开放场地交火时的长期战斗。

```formula
DPM = alpha x 60 / reload

在弹夹炮的情况下，整个循环都要计算：弹夹的伤害除以发射和装填所需时间。 ```

这是一种上限，而不是测量值。没有任何人会在冷却结束后连续发射一整分钟：瞄准、重新定位以及等待目标都会影响到时间，所以纸面上 DPM 最好的炮往往会输给每发伤害更高的炮。

车组技能、装备和消耗品都会提高这个数值，这就是为什么标配配置的数值和完全装备的车辆所达到的数值可能相差五分之一或更多。
