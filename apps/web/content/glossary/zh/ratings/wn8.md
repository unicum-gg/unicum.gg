一个社区表现评分，针对玩家在其实际使用的车辆中，期望的伤害、击杀、侦查和基础防御进行评分，同时加上胜率的因素。

WN8回答了一个原始平均值无法解答的问题。每场战斗1,800伤害算好吗？在Tier X重型坦克上，这个表现并不突出，而在Tier V中型坦克上则很出色。WN8将账户上每辆车辆的表现与服务器该辆车辆的平均值做比较，因此主要驾驶Tier VI的玩家是与Tier VI进行比对，而不是与整个玩家群体。

它由WN团队于2013年发布，作为WN7的继任者，WN7的分级惩罚机制使其容易被操纵。五个比例用于计算：伤害、击杀、侦查、失去的占点和胜率，每个比例都除以所玩车辆的期望值，并向下取整为零，同时在伤害的项下设有上限，以避免某个强项完全掩盖其他表现。

```formula
980 x rDAMAGE + 210 x rDAMAGE x rFRAG + 155 x rFRAG x rSPOT + 75 x rDEF x rFRAG + 145 x min(1.8, rWIN)

每个比例都是经过修正的形式：原始比例经过下限调整，并且限制在其所乘以的伤害比例之内。 ```

伤害大约占总权重的四分之三，这是人们对此的常见抱怨：一个在后方被动收割伤害的玩家得分往往高于其数值所应有的水平。胜率项的上限为1.8，因此一个强大的编队不能无限膨胀一个弱账户的分数。

由于期望值反映的是服务器的快照，WN8会随着玩家群体和车辆的变化而漂移。获得增强的坦克会在下一个数据集更新时提高所有驾驶该坦克玩家的门槛。WN8也是对账户整个历史的累积，因此几千场早期的战斗在多年后依旧会影响分数，这也是大多数玩家更关注自己近期WN8的原因。
