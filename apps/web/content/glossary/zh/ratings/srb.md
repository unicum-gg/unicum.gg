要塞评级不再只是以战斗场次设定门槛，而是对战斗量给予加成，因此，一个经过数百场战斗证明自身实力的军团，会排在仅用二十场战斗便取得相同 SR 的军团之前。

SR 有意忽略军团参加了多少场战斗。SRB 使用同一评级，再乘以一个随累计战斗场次增长的系数，因此它只会高于作为其计算基础的 SR。

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

由于采用对数计算，最初的一百场战斗远比第一千场战斗更有价值。 ```

所有等级都有意使用同一个战斗场次常数，这是因为 X级冲突战会持续进行，而攻城战每年只有几周会集中进行，因此实际进行场次更多的等级会获得更高的加成。战斗场次加成可以区分在数百场战斗中保持某一评级的军团，以及仅用二十场战斗就达到该评级的军团。
