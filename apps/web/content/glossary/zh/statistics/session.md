在一段时间内玩的一系列战斗，由追踪器从账户的两个快照之间的差异重构而成。

Wargaming 的 API 提供账户的总计，而不是其单独的战斗。追踪器定期快照这些总计，两个快照之间的差异恰好就是在此之间进行的战斗，包括它们的伤害、击杀和结果。

这个差异就是一个会话。它是一个网站可以展示玩家今天所做的事情，而不是他们自2013年以来所做的，最近的评级就是基于这个计算的。

其分辨率取决于账户快照的频率，因此会话是一段游戏块，而不是精确的开始和结束时间，并且在快照之前进行的战斗会记录在该快照的会话中。
