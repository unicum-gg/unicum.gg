覆盖率是一个统计网站实际跟踪的服务器玩家群体的数量，以及这些账户有多新。

没有任何追踪器能够看到每个账户。Wargaming 的 API 有速率限制，因此网站通过战队名册和搜索发现账户，然后以其能够承担的节奏刷新每个账户。覆盖率是该区域活跃玩家的分享以及每个账户最近一次更新的时间。

这很重要，因为每个排行榜和每个服务器平均值都是基于被追踪的玩家群体来计算的，而不是整个服务器。宽泛的覆盖率使得这些数字具有代表性，稀疏的覆盖率则使其成为样本。
