Un al doilea vizor care arată unde crede serverul că este îndreptat tunul, ceea ce este ceea ce este de fapt rezolvat împotriva focului.

Clientul desenează cercul de țintire imediat, serverul decide unde merge proiectilul. Întârzierea de rețea pune cele două puțin mai departe, iar la distanță această diferență este mai mare decât un punct slab.

Activarea vizorului de server desenează și poziția autoritară. Jucătorii care fac tir de precizie trag după crucea de server și nu după cea a clientului, motiv pentru care a fost un mod mult înainte de a deveni o setare.
