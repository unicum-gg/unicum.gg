Cât de departe poate un vehicul să observe inamicii, în metri, limitat la 445 metri indiferent cât de mare devine cifra.

Raza de vedere este atingerea viziunii proprii a unui vehicul. Aceasta provine din turela, este îmbunătățită de instruirea comandantului, opticile și opticile acoperite, și este redusă atunci când comandantul este rănit.

Limita absolută este de 445 metri: nimic nu este observat dincolo de aceasta. Totuși, raza de vedere peste această limită nu este irosită, deoarece camuflajul este scăzut din ea. Împotriva unei ținte bine ascunse, raza de vedere suplimentară este ceea ce readuce distanța de observare aproape de limită.

Viziunea este verificată din puncte specifice pe vehicul, astfel că un șasiu așezat în spatele unei înălțimi vede mai puțin decât sugerează cifra, iar un vehicul care își scoate doar turela vede de acolo.
