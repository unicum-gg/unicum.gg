Cursa principală: cincisprezece împotriva cincisprezece, echipe formate de matchmaker, pe un pool rotativ de hărți.

Bătăliile Random sunt locul unde aproape fiecare cont își petrece aproape tot timpul, așa că este modul despre care fiecare statistică vorbește implicit. Două echipe de cincisprezece sunt formate de matchmaker, plasate pe o hartă pentru unul dintre cele trei obiective și li se oferă cincisprezece minute.

O bătălie se încheie când o echipă este distrusă, baza este capturată sau timpul se termină, ceea ce este un egal. Totul derivă din asta: rata de câștig este măsurată aici, valorile așteptate sunt calculate aici, iar reputația unui vehicul este construită aici.
