A second crosshair showing where the server thinks the gun is pointing, which is what the shot is actually resolved against.

The client draws the aiming circle immediately, the server decides where the shell goes. Network delay puts the two slightly apart, and at range that gap is wider than a weak spot.

Turning on the server reticle draws the authoritative position as well. Players who snipe fire on the server crosshair rather than the client one, which is why it was a mod long before it became a setting.
