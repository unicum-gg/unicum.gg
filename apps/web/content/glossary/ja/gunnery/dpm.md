武器が持続的な交換でどれだけのダメージを与えるか、アルファに発射頻度を掛けたものです。

DPMはアルファの持続的な対応物です。これは、銃が発射を止めることなく生産するものを示し、両方の車両がオープンで交換している長い殴り合いを決定します。

```formula
DPM = alpha x 60 / reload

マガジン式の銃の場合、全サイクルがカウントされます：クリップのダメージを発射と再装填の時間で割ります。 ```

これは上限であり、測定値ではありません。誰も一分間クールダウンして発射することはありません。狙いを定めたり、再配置したり、ターゲットを待つことがすべて時間を削減するため、書面上で最高のDPMを持つ銃は、しばしば一発あたりのダメージが大きいものに負けます。

乗員のスキル、装備、消耗品すべてがこれを引き上げます。そのため、ストック構成で表示される数値と、完全に装備された車両が達成する数値は5分の1以上異なることがあります。
