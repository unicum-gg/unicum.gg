WNXは、与えたダメージに加え支援ダメージを計算し、勝率の項を完全に除いた現代の車両ごとの評価です。

WNXはWN8の形状を保ち、車両ごとの期待値との比率を使い、計算する内容が変更されています。トラッキングとラジオ支援は、その価値の三分の二でダメージに追加されるため、味方のためにスポットしたり、履帯を妨害したりすることは無視されるのではなく、本来の貢献度としてスコアに反映されます。

勝率の成分はありません。結果に基づく用語はプラトーンや長いアカウントをより高く評価するため、WNXはバトル中にプレイヤーが実際に行ったことのみをスコアします：ダメージと支援、破壊数およびスポット数を、車両が期待される生産量に対して計算します。

```formula
raw = 750 x rDAMAGE + 200 x rFRAG + 50 x rSPOT, then raw x (raw / 1000) ^ 0.45 x 1.65

# この尾部指数はスケールの上部を広げるため、良いアカウントと例外的なアカウントとの間のギャップが圧縮されずに表示されます。 ```

期待値はtomato.ggから来ており、大量のトラッキングされたアカウントから再計算されています。これはunicum.ggのデフォルト評価で、車両が実際にどのようにプレイされているかに最も早く反応します。
