WNXは、与えたダメージに加えてアシストダメージも数え、勝率の項を完全に除外する車両別レーティングです。

WNXはWN8の形式と車両ごとの期待値に対する比率を維持しながら、集計対象を変更しています。履帯切断アシストと観測アシストは、それぞれの値の3分の2をダメージに加算されるため、味方のために敵を発見したり履帯を切断したりする行動は、無視されるのではなく、実際の貢献度として評価されます。

勝率の要素はありません。結果に基づく項目は、プレイヤーの実力を測る以上に、プラトーンを組むことや長期間運用されたアカウントを有利に評価するため、WNXは戦闘でプレイヤーが行ったことだけを、車両が生み出すと予想される値に対するダメージとアシスト、撃破数、観測数として評価します。

```formula
raw = 750 x rDAMAGE + 200 x rFRAG + 50 x rSPOT, then raw x (raw / 1000) ^ 0.45 x 1.65

末尾の指数はスケールの上位部分を引き伸ばすため、優れたアカウントと卓越したアカウントの差が圧縮されず、見分けられる状態に保たれます。 ```

期待値は、追跡対象となっている大量のアカウントのサンプルから再計算されます。これは、現在その車両が実際にどのようにプレイされているかに最も早く反応するため、unicum.ggでのデフォルトのレーティングです。
