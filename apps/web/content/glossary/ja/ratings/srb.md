戦闘数を単なる条件として扱うのではなく評価に反映する拠点レーティングで、数百戦を通じて実力を証明したクランは、20戦で同じSRを獲得したクランより上位になります。

SRは、クランがどれだけプレイしたかを意図的に考慮しません。SRBは、その同じレーティングに、それまでの戦闘数に応じて増加する項を乗算するため、基となるSRより低くなることはありません。

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

対数式なので、最初の100戦は1000戦目よりはるかに大きな価値があります。 ```

すべてのTierで戦闘数の定数を1つに統一しているのは意図的です。前衛戦Tier Xは継続的にプレイされる一方、進撃戦は年に数週間だけ集中的に開催されるため、実際に多くプレイされるTierほど大きなボーナスを獲得します。この戦闘数ボーナスにより、数百戦にわたってレーティングを維持したクランと、20戦でそのレーティングに到達したクランが区別されます。
