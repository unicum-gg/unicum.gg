プレイヤーのダメージ、キル、スポット、基地防衛に対する期待値に基づいてスコアを与えるコミュニティパフォーマンス評価で、勝率の項目も追加されています。

WN8は、単純な平均では答えられない質問に答えます。1,800ダメージのバトルは良いのでしょうか？Tier Xの重戦車では平凡ですが、Tier Vの中戦車では卓越しています。WN8はアカウントの各車両を同じ車両のサーバー平均と比較するため、主にTier VIを運転するプレイヤーは全体の人口ではなくTier VIで測定されます。

この評価は2013年にWNチームによってWN7の後継として発表されました。WN7のティアペナルティは簡単に操作できたためです。五つの比率がこの評価に反映されています：ダメージ、フラグ、スポット、ドロップしたキャプチャポイント、勝率。それぞれはプレイした車両の期待値で割られ、ゼロで切り捨てられ、ダメージの項目に制限されているため、1つの強い軸が他を担うことはできません。

```formula
980 x rDAMAGE + 210 x rDAMAGE x rFRAG + 155 x rFRAG x rSPOT + 75 x rDEF x rFRAG + 145 x min(1.8, rWIN)

この比率はすべて修正された形です：生の比率はその下限によってシフトされ、乗じるダメージ比率に制限されています。 ```

ダメージはおおよそ重みの三分の二を占めています。これは通常の不満点であり、後方からダメージを稼ぐ受動的なプレイヤーが実際の数字以上に良いスコアを得てしまうことです。勝率の項目は1.8で制限されているため、強いプラトーンが弱いアカウントを無限に膨らませることはできません。

期待値がサーバーのスナップショットであるため、WN8は人口や車両が変化するにつれて漂流します。バフされた戦車は、次のデータセット更新時にそれを運転する全ての人に対して基準を引き上げます。WN8はまた、アカウントの全歴史に渡って累積されるため、数千の初期バトルが何年もあとに影響を与え続けることがあります。これが、ほとんどのプレイヤーが最近のWN8を注視する理由です。
