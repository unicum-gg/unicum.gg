Freie Erfahrung kann für jedes Fahrzeug oder Modul ausgegeben werden, wird als kleiner Anteil aller verdienten Erfahrung gesammelt und kann mit Gold von Elitefahrzeugen umgewandelt werden.

Ein kleiner Prozentsatz der in jedem Gefecht verdienten Erfahrung wird als Freie Erfahrung gutgeschrieben. Sie ist nicht an ein Fahrzeug gebunden und kann daher verwendet werden, um eine Ausgangskonfiguration zu überspringen, ein Modul direkt freizuschalten oder in einem Forschungsbaum voranzukommen.

Auf einem Elitefahrzeug angesammelte Erfahrung kann ebenfalls mit Gold in Freie Erfahrung umgewandelt werden. So können Spieler, die eine Fahrzeuglinie abgeschlossen haben, ein ungenutztes Erfahrungsguthaben für Fortschritte an anderer Stelle einsetzen.
