Der Gegenstand, mit dem Zubehör von einem Fahrzeug ausgebaut werden kann, ohne dafür Gold zu bezahlen.

Zubehör kann gegen eine Gebühr jederzeit ausgebaut werden: entweder mit Gold oder mit einer bei Events und Aufträgen verdienten Ausbau-Anweisung. Standardzubehör kann außerdem mit Verlust für Kreditpunkte verkauft werden.

Dadurch kann eine gute Konfiguration auf mehreren Fahrzeugen verwendet werden, weshalb die meisten Spieler Verbessertes Zubehör, von dem sie nur ein Exemplar besitzen, auf diese Weise einsetzen.
