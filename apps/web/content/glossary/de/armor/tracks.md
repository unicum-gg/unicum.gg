Das Laufwerk, das das Fahrzeug bei einer Zerstörung bewegungsunfähig macht und im intakten Zustand Granaten wie eine Schottpanzerung abfängt.

Eine zerstörte Kette bringt das Fahrzeug zum Stillstand, bis sie repariert ist, was die häufigste Methode ist, ein Ziel lange genug festzuhalten, um es zu zerstören. Die Kette eines Gegners zu zerstören und ihn von Verbündeten ausschalten zu lassen, ist eine eigenständige Spielweise.

Intakte Ketten dienen ebenfalls als Panzerung. Sie zählen als Schottpanzerung, sodass eine Granate, die zuerst die Kette trifft, Durchschlagskraft verliert, bevor sie die Wanne erreicht, und ein Fahrzeug kann seine Kette bewusst so ausrichten, dass sie einen Treffer abfängt.

Schaden an einem Ziel, das ein Verbündeter durch Kettenzerstörung bewegungsunfähig gemacht hat, wird als Unterstützungsschaden durch Kettenzerstörung gutgeschrieben, sodass das Bewegungsunfähigmachen eines Gegners in der Statistik erscheint.
