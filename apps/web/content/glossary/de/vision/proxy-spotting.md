term: Nahaufklärung

Die Regel, nach der jedes Fahrzeug innerhalb von 50 metres unabhängig von seiner Tarnung aufgeklärt wird, solange eine Sichtlinie besteht.

Innerhalb von 50 metres spielt Tarnung keine Rolle mehr. Ein Fahrzeug in diesem Radius wird entdeckt, sobald irgendjemand eine Sichtlinie zu ihm hat, weshalb das Vorbeifahren an einer Buschreihe alles aufdeckt, was sich darin versteckt.

Aufklärer nutzen dies gezielt: Eine schnelle Durchfahrt durch eine vermutete Position klärt für das Team alles darin auf, allerdings wird der Aufklärer dabei selbst aufgeklärt.
