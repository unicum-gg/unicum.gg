Ein zweites Fadenkreuz, das anzeigt, wohin das Geschütz laut Server zielt und anhand dessen der Schuss tatsächlich berechnet wird.

Der Client zeichnet den Zielkreis sofort, während der Server entscheidet, wohin die Granate fliegt. Durch die Netzwerkverzögerung liegen die beiden leicht auseinander, und auf große Entfernung ist dieser Abstand größer als eine Schwachstelle.

Wenn das Server-Fadenkreuz aktiviert wird, zeigt es zusätzlich die maßgebliche Position an. Spieler, die auf große Entfernung schießen, feuern anhand des Server-Fadenkreuzes statt des Client-Fadenkreuzes, weshalb es schon lange eine Mod war, bevor es zu einer Einstellung wurde.
