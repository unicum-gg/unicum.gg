Die fahrzeugspezifischen Serverdurchschnittswerte, mit denen eine Wertung einen Spieler vergleicht, zeigen, was ein typischer Spieler mit genau diesem Panzer erreicht.

Jede fahrzeugspezifische Wertung benötigt eine Vergleichsbasis. Erwartungswerte bilden diese Basis, wobei eine Zeile pro Fahrzeug den durchschnittlichen Schaden, die Abschüsse, die Aufklärung und die Verteidigung auf dem Server angibt. Die eigenen Werte eines Spielers werden durch diese Werte geteilt, um die Verhältnisse zu erhalten, mit denen die Wertungsformel arbeitet.

Die Tabellen werden von der Community und nicht von Wargaming gepflegt und regelmäßig anhand einer großen Stichprobe von Konten neu berechnet. Zwischen zwei Veröffentlichungen verändert sich die Fahrzeugauswahl fortlaufend: Neue Premium- und Belohnungsfahrzeuge haben noch keine eigene Zeile, weshalb eine Wertung sie entweder auslässt oder auf den Durchschnitt vergleichbarer Fahrzeuge derselben Stufe und Klasse zurückgreift.

Eine Aktualisierung des Datensatzes verändert unbemerkt die Wertung aller Spieler. Wenn ein Fahrzeug verstärkt wird und der Server damit mehr Schaden verursacht, steigt der Erwartungswert und dieselbe Leistung wird beim nächsten Mal niedriger bewertet. Das ist beabsichtigt: Die Wertung misst einen Spieler am aktuellen Server und nicht an einem unveränderlichen Vergleichsstand.
