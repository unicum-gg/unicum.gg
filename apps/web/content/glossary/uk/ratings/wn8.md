Спільнотний рейтинг ефективності, який оцінює гравця за шкодою, знищеннями, виявленням і захистом бази, очікуваними для техніки, на якій він фактично грає, а також враховує відсоток перемог.

WN8 відповідає на запитання, на яке не може відповісти просте середнє значення. Чи добре завдавати 1,800 шкоди за бій? Для важкого танка X рівня це нічого особливого, а для середнього танка V рівня це винятковий результат. WN8 порівнює кожну машину в обліковому записі із середнім показником сервера для цієї самої машини, тож гравця, який переважно грає на VI рівні, порівнюють з іншими гравцями на VI рівні, а не з усією спільнотою.

Його опублікувала у 2013 році команда WN як наступника WN7, чий штраф за рівень давав змогу легко маніпулювати рейтингом. Він враховує п’ять співвідношень: шкоду, фраги, виявлення, збиті очки захоплення та відсоток перемог. Кожен показник ділиться на очікуване значення для зіграної техніки, обмежується знизу нулем і зверху показником шкоди, щоб один сильний аспект не міг компенсувати всі інші.

```formula
980 x rDAMAGE + 210 x rDAMAGE x rFRAG + 155 x rFRAG x rSPOT + 75 x rDEF x rFRAG + 145 x min(1.8, rWIN)

Кожне співвідношення тут подано у скоригованій формі: початкове співвідношення зсунуте на своє мінімальне значення та обмежене співвідношенням шкоди, на яке воно множиться. ```

На шкоду припадає приблизно три чверті ваги, що й спричиняє найпоширенішу претензію до рейтингу: пасивний гравець, який набиває шкоду здалеку, отримує вищий результат, ніж заслуговує за іншими показниками. Показник відсотка перемог обмежено значенням 1.8, тому сильний взвод не може безмежно завищувати рейтинг слабкого облікового запису.

Оскільки очікувані значення є знімком стану сервера, WN8 змінюється разом зі спільнотою та технікою. Якщо танк посилюють, під час наступного оновлення набору даних планка підвищується для всіх, хто на ньому грає. WN8 також накопичується за всю історію облікового запису, тому кілька тисяч ранніх боїв продовжують впливати на нього навіть через роки, через що більшість гравців натомість стежать за своїм нещодавнім WN8.
