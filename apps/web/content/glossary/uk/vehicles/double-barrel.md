Гарматна система з двома стволами, яка може стріляти по одному снаряду або обома одночасно залпом.

Двоствольні машини заряджають два снаряди й вибирають, як їх використати: чергувати одиночні постріли для стабільного завдання шкоди або зробити залп, випустивши обидва снаряди одночасно для подвійної разової шкоди.

Після залпу гармата надовго блокується для перезаряджання, тож це той самий компроміс, на який іде машина з автоматом заряджання, але зведений до одного рішення на кожне перезаряджання.
