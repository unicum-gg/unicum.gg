Обладнання, що збільшує потужність двигуна та максимальну швидкість, стандартне рішення для машини, яка всюди запізнюється.

Турбонагнітач збільшує максимальну швидкість і потужність двигуна, тому машина швидше розганяється та краще зберігає швидкість на м’яких ґрунтах. Для середнього танка, який має першим зайняти позицію, він часто корисніший за будь-яке обладнання для вогневої потужності.

Це стандартний вибір для слота мобільності, так само як досилач для слота вогневої потужності.
