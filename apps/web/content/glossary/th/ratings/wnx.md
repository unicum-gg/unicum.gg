คะแนน WNX ใหม่ล่าสุดที่นับความเสียหายที่ช่วยเหลือควบคู่ไปกับความเสียหายที่ทำได้และไม่รวมอัตราการชนะไว้เลย

คะแนน WNX ยังรักษารูปแบบของ WN8 อัตราส่วนที่เทียบกับค่าที่คาดหวังต่อยานพาหนะ และเปลี่ยนสิ่งที่นับ การติดตามและการช่วยส่งสัญญาณถูกเพิ่มเข้าไปในความเสียหายที่สองในสามของมูลค่าของมัน ดังนั้นการมองเห็นสำหรับเพื่อนร่วมทีมและการปิดบังรางจะถูกคะแนนในฐานะที่เป็นการมีส่วนร่วมที่พวกเขาเป็น แทนที่จะถูกละเลย

มันไม่มีส่วนประกอบอัตราการชนะ เงื่อนไขที่อิงจากผลลัพธ์จะให้รางวัลการจัดกลุ่มและบัญชีที่ยาวนานมากกว่าสิ่งที่วัดผู้เล่น ดังนั้นคะแนน WNX จึงนับเฉพาะสิ่งที่ผู้เล่นทำในสงคราม: ความเสียหายบวกความช่วยเหลือ การฆ่าและการมองเห็นเทียบกับสิ่งที่ยานพาหนะคาดว่าจะสร้าง

```formula
raw = 750 x rDAMAGE + 200 x rFRAG + 50 x rSPOT, then raw x (raw / 1000) ^ 0.45 x 1.65

*หมายเหตุ: ตัวพหุคูณดึงขอบด้านบนของมาตราส่วน ดังนั้นความแตกต่างระหว่างบัญชีที่ดีและยอดเยี่ยมจะยังคงมองเห็นได้แทนที่จะถูกบีบอัด* ```

ค่าคาดหวังมาจาก tomato.gg ซึ่งคำนวณใหม่จากตัวอย่างขนาดใหญ่ของบัญชีที่ติดตาม นี่เป็นคะแนนเริ่มต้นบน unicum.gg เนื่องจากตอบสนองต่อวิธีการเล่นของยานพาหนะในปัจจุบันได้อย่างรวดเร็ว.
