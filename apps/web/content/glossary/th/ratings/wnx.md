เรตติ้งรายคันแบบสมัยใหม่ที่นับความเสียหายจากการช่วยเหลือรวมกับความเสียหายที่ทำได้ และตัดส่วนอัตราชนะออกทั้งหมด.

WNX ยังคงโครงสร้างของ WN8 และอัตราส่วนที่เทียบกับค่าคาดหมายรายคันเอาไว้ แต่เปลี่ยนสิ่งที่นำมาคำนวณ โดยเพิ่มความช่วยเหลือจากการตรวจจับและการทำลายสายพานเข้าไปในความเสียหายที่สองในสามของมูลค่า ดังนั้นการตรวจจับศัตรูให้อยู่ในระยะการมองเห็นของพันธมิตรและการทำให้สายพานของศัตรูขาดจึงถูกนับเป็นผลงานที่ผู้เล่นทำได้จริงแทนที่จะถูกละเลย

ไม่มีองค์ประกอบอัตราชนะ ตัวชี้วัดที่อิงผลลัพธ์ให้รางวัลกับการเล่นหมวดและบัญชีที่เล่นมานานมากกว่าการวัดฝีมือของผู้เล่น ดังนั้น WNX จึงให้คะแนนเฉพาะสิ่งที่ผู้เล่นทำได้ในการรบ นั่นคือความเสียหายรวมกับความช่วยเหลือ จำนวนยานที่ทำลายได้ และจำนวนยานที่ตรวจจับได้ เมื่อเทียบกับสิ่งที่คาดหมายว่ายานคันนั้นจะทำได้

```formula
raw = 750 x rDAMAGE + 200 x rFRAG + 50 x rSPOT, then raw x (raw / 1000) ^ 0.45 x 1.65

เลขชี้กำลังส่วนท้ายจะขยายช่วงคะแนนด้านบน ทำให้ยังมองเห็นช่องว่างระหว่างบัญชีที่เล่นได้ดีและบัญชีที่ยอดเยี่ยมได้ แทนที่จะทำให้คะแนนเบียดเข้าหากัน ```

ค่าคาดหมายจะคำนวณใหม่จากกลุ่มตัวอย่างขนาดใหญ่ของบัญชีที่มีการติดตามข้อมูล นี่คือเรตติ้งเริ่มต้นบน unicum.gg เพราะตอบสนองได้เร็วที่สุดต่อวิธีที่ผู้เล่นใช้ยานพาหนะจริงในปัจจุบัน
