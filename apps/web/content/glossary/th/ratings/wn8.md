การประเมินผลการทำงานของผู้เล่นในชุมชนที่ให้คะแนนจากความเสียหาย การฆ่า การสอดแนม และการป้องกันฐานที่คาดหวังจากยานพาหนะที่ผู้เล่นใช้จริง โดยมีอัตราการชนะเป็นปัจจัยเพิ่มเติม

WN8 ตอบคำถามที่ค่าเฉลี่ยดิบไม่สามารถทำได้ ค่าความเสียหาย 1,800 ต่อการต่อสู้ดีไหม? สำหรับรถถัง Tier X หนักนั้นถือว่าสูงกว่ามาตรฐาน แต่นั่นถือว่ายอดเยี่ยมสำหรับ Tier V ปานกลาง WN8 จะเปรียบเทียบทุกยานพาหนะในบัญชีหนึ่ง ๆ กับค่าเฉลี่ยของเซิร์ฟเวอร์สำหรับยานพาหนะเดียวกัน ดังนั้นผู้เล่นที่ขับ Tier VI เป็นหลักจึงถูกวัดจาก Tier VI แทนที่จะเป็นประชากรทั้งหมด

มันถูกเผยแพร่ในปี 2013 โดยทีม WN เป็นผู้สืบทอดต่อจาก WN7 ซึ่งมีโทษตามระดับที่ทำให้การใช้ประโยชน์จากมันง่ายหาย สิ่งที่ให้น้ำหนักกับมันมีอยู่ 5 ส่วน: ความเสียหาย การฆ่า การสอดแนม คะแนนการเข้ายึดที่ลดลง และอัตราการชนะ ซึ่งแต่ละส่วนจะถูกแบ่งด้วยค่าเฉลี่ยที่คาดหวังสำหรับรถถังที่เล่น โดยถูกตัดที่ศูนย์ และมีการกำหนดค่าต่อความเสียหายเพื่อไม่ให้แกนที่แข็งแกร่งทำให้ค่าที่เหลือสูงขึ้นไปได้

```formula
980 x rDAMAGE + 210 x rDAMAGE x rFRAG + 155 x rFRAG x rSPOT + 75 x rDEF x rFRAG + 145 x min(1.8, rWIN)

แต่ละอัตราส่วนที่นี่เป็นรูปแบบที่แก้ไขแล้ว: อัตราส่วนดิบที่ถูกเลื่อนด้วยค่า floor ถูกจำกัดด้วยอัตราส่วนความเสียหายที่มันคูณ ```

ความเสียหายมีน้ำหนักประมาณสามในสี่ซึ่งเป็นเรื่องที่มักจะถูกวิจารณ์เกี่ยวกับมัน ผู้เล่นที่ passive ที่เก็บความเสียหายจากด้านหลังมีคะแนนสูงกว่าที่ตัวเลขควรจะมี อัตราการชนะนั้นถูกจำกัดที่ 1.8 ดังนั้นกลุ่มที่แข็งแกร่งจึงไม่สามารถทำให้บัญชีที่อ่อนแอเพิ่มขึ้นได้ตลอดไม่รู้จบ

เนื่องจากค่าเฉลี่ยที่คาดหวังคือภาพรวมของเซิร์ฟเวอร์ WN8 จึงมีการเปลี่ยนแปลงตามที่ประชากรและยานพาหนะเปลี่ยนแปลง รถถังที่ถูกเสริมกำลังจะเพิ่มมาตรฐานให้กับผู้ที่ขับมันในอัปเดตข้อมูลชุดถัดไป WN8 ยังสะสมตลอดประวัติศาสตร์ของบัญชี ไม่กี่พันการต่อสู้ในช่วงต้นยังคงมีน้ำหนักกับมันอยู่หลายปีต่อมา นี่คือเหตุผลที่ผู้เล่นส่วนใหญ่จึงดู WN8 ที่เพิ่งเกิดขึ้นล่าสุดของพวกเขากันมากกว่า
