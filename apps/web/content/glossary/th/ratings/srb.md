อันดับฐานที่มั่นที่ให้รางวัลตามปริมาณการรบแทนที่จะใช้เป็นเพียงเกณฑ์ขั้นต่ำ ทำให้กองทัพที่พิสูจน์ตัวเองผ่านการรบหลายร้อยครั้งมีอันดับสูงกว่ากองทัพที่มี SR เท่ากันจากการรบเพียงยี่สิบครั้ง

SR จงใจไม่คำนึงว่ากองทัพเล่นมากเพียงใด ส่วน SRB นำอันดับเดียวกันนั้นมาคูณด้วยพจน์ที่เพิ่มขึ้นตามจำนวนการรบที่ผ่านมา จึงมีค่าได้เพียงสูงกว่า SR ที่ใช้เป็นฐาน

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

เป็นแบบลอการิทึม ดังนั้นการรบร้อยครั้งแรกจึงมีค่ามากกว่าการรบครั้งที่หนึ่งพันอย่างมาก ```

มีการใช้ค่าคงที่ของปริมาณการรบค่าเดียวกันในทุกระดับโดยตั้งใจ เนื่องจากการปะทะ ระดับ X มีการเล่นอย่างต่อเนื่อง ขณะที่การรบรุกคืบเปิดเป็นช่วงๆ เพียงไม่กี่สัปดาห์ต่อปี ดังนั้นระดับที่มีการเล่นมากกว่าจริงจึงได้รับโบนัสมากกว่า โบนัสตามปริมาณการรบคือสิ่งที่แยกกองทัพซึ่งรักษาอันดับไว้ได้ตลอดการรบหลายร้อยครั้งออกจากกองทัพที่เพิ่งทำอันดับนั้นได้จากการรบยี่สิบครั้ง
