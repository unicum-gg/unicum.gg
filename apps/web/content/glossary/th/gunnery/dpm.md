จำนวนความเสียหายที่ปืนทำได้ในช่วงการแลกเปลี่ยนอย่างยืนยาว โดยอัลฟาคูณกับความถี่ในการยิง

DPM คือเกณฑ์ที่ยืนยาวเมื่อเปรียบเทียบกับอัลฟา มันบอกได้ว่าปืนหนึ่งจะทำงานได้อย่างไรหากไม่หยุดยิง ซึ่งเป็นสิ่งที่ตัดสินผลในการต่อสู้ที่ยาวนานเมื่อรถทั้งสองคันกำลังแลกเปลี่ยนกันในที่โล่ง

```formula
DPM = alpha x 60 / reload

ในปืนที่มีแม็กกาซีน วงจรทั้งหมดจะถูกนับ: ความเสียหายของคลิปหารด้วยเวลาที่ใช้ในการยิงและโหลดมัน ```

มันเป็นเพดาน ไม่ใช่การวัด โดยปรกติไม่มีใครยิงตามเวลาเต็มหนึ่งนาที การเล็ง การเปลี่ยนตำแหน่ง และการรอเป้าหมายล้วนทำให้ตัวเลขนี้ถูกตัดทอน ซึ่งหมายความว่าปืนที่มี DPM ดีที่สุดในกระดาษมักจะแพ้ให้กับปืนที่ทำความเสียหายได้มากกว่าในแต่ละนัด

ทักษะของทีมงาน อุปกรณ์ และของใช้ทั้งหมดช่วยเพิ่ม DPM ซึ่งเป็นเหตุผลว่าทำไมตัวเลขที่แสดงสำหรับการกำหนดค่ามาตรฐานและตัวเลขที่รถที่ติดตั้งอุปกรณ์เต็มรูปแบบสามารถแตกต่างกันได้มากถึงหนึ่งในห้าหรือมากกว่านั้น.
