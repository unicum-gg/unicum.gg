ปริมาณของผู้เล่นในเซิร์ฟเวอร์ที่เว็บไซต์สถิติติดตามได้จริง และบัญชีเหล่านั้นมีความสดใหม่เพียงใด

ไม่มีผู้ติดตามคนใดที่สามารถเห็นบัญชีทุกบัญชีได้ API ของ Wargaming มีการจำกัดอัตรา ดังนั้นเว็บไซต์จึงค้นพบบัญชีจากรายชื่อแคลนและการค้นหา จากนั้นจึงอัปเดตบัญชีเหล่านั้นตามจังหวะที่พวกเขาสามารถทำได้ Coverage คือส่วนแบ่งของผู้เล่นที่ใช้งานในภูมิภาคที่เว็บไซต์มีอยู่ และความถี่ที่แต่ละบัญชีถูกอัปเดต

มันมีความสำคัญเพราะทุกกระดานผู้นำและค่าเฉลี่ยของเซิร์ฟเวอร์จะคำนวณจากประชากรที่ถูกติดตาม ไม่ใช่จากเซิร์ฟเวอร์ทั้งหมด Coverage ที่กว้างทำให้ตัวเลขเหล่านั้นเป็นตัวแทน ในขณะที่ coverage ที่บางทำให้เป็นเพียงกลุ่มตัวอย่างเท่านั้น.
