บล็อกของการต่อสู้ที่เล่นในคราวเดียว ซึ่งสร้างขึ้นโดยตัวติดตามจากความแตกต่างระหว่างภาพถ่ายสองภาพของบัญชี

API ของ Wargaming ให้ข้อมูลรวมของบัญชี ไม่ใช่การต่อสู้แต่ละครั้ง ตัวติดตามจะทำการถ่ายภาพรวมเหล่านั้นเป็นประจำ และความแตกต่างระหว่างภาพถ่ายสองภาพคือจำนวนการต่อสู้ที่เล่นระหว่างนั้น ซึ่งรวมถึงความเสียหาย การฆ่า และผลที่ได้

ความแตกต่างนั้นคือเซสชัน มันเป็นวิธีที่เว็บไซต์สามารถแสดงว่าผู้เล่นทำอะไรในวันนี้ แทนที่จะดูสิ่งที่พวกเขาทำตั้งแต่ปี 2013 และมันเป็นสิ่งที่คะแนนล่าสุดถูกคำนวณขึ้นตาม

ความละเอียดของมันขึ้นอยู่กับความถี่ที่บัญชีถูกถ่ายภาพ ดังนั้นเซสชันจึงเป็นบล็อกของการเล่น มากกว่าเป็นเวลาเริ่มต้นและสิ้นสุดที่แน่นอน โดยการต่อสู้ที่เล่นก่อนการถ่ายภาพจะอยู่ในเซสชันของภาพถ่ายนั้น.
