Un joueur dans la file d’attente publique, terme utilisé pour distinguer les batailles aléatoires des parties de clan organisées.

Pub est l’abréviation de public, c’est-à-dire la file d’attente ouverte que tout le monde peut rejoindre, par opposition à un format de clan où les quinze joueurs sont sélectionnés et reçoivent des instructions. Un pubbie est un joueur qui se trouve dans cette file.

Ce mot sous-entend généralement que rien ne peut être coordonné, ce qui fait des batailles aléatoires et des Guerres de clans deux jeux véritablement différents.
