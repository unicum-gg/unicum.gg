L’écran auquel le jeu revient entre les batailles et qui contient tous les véhicules possédés par un compte.

Le garage permet d’acheter, d’équiper, de réparer les véhicules et de leur affecter un équipage, ainsi que de rejoindre la file d’attente de bataille. Chaque véhicule occupe un emplacement, et les emplacements s’achètent avec de l’or, ce qui limite discrètement l’accumulation de chars.

Les joueurs disent qu’un véhicule est dans leur garage pour indiquer qu’ils le possèdent, et un emplacement de garage est ce qu’un véhicule de récompense leur coûte réellement.
