---
term: Réticule serveur
aliases:

Un second réticule indiquant où le serveur considère que le canon est pointé, position utilisée pour calculer réellement le tir.

Le client affiche immédiatement le cercle de visée, tandis que le serveur décide où va l'obus. La latence réseau crée un léger décalage entre les deux et, à longue distance, cet écart peut être plus grand qu'un point faible.

Activer le réticule serveur affiche également la position de référence. Les joueurs qui tirent de loin font feu en se fiant au réticule du serveur plutôt qu'à celui du client, raison pour laquelle il existait sous forme de mod bien avant de devenir un paramètre.
