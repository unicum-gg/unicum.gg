Dégâts infligés aux ennemis situés dans votre propre base, comptabilisés en points de défense et mesurés selon le nombre de points de capture annulés.

Un véhicule qui capture une base perd les points qu’il a personnellement accumulés dès qu’il est touché. Le joueur à l’origine du tir reçoit les points de capture qu’il a annulés, lesquels sont enregistrés dans les statistiques du compte comme points de défense.

C’est le moyen le moins coûteux pour un joueur de décider de l’issue d’une bataille : un seul tir dans le cercle peut effacer une minute de capture effectuée par trois véhicules, et le compteur en est la seule trace dans le registre.
