La file d'attente principale où quinze joueurs affrontent quinze autres joueurs, avec des équipes constituées par le système de matchmaking sur une sélection de cartes en rotation.

Les Batailles aléatoires sont le mode dans lequel presque tous les comptes passent la quasi-totalité de leur temps, si bien qu'il s'agit du mode auquel toutes les statistiques font implicitement référence. Deux équipes de quinze joueurs sont constituées par le système de matchmaking, placées sur une carte avec l'un des trois objectifs, puis disposent de quinze minutes.

Une bataille prend fin lorsqu'une équipe est détruite, que la base est capturée ou que le temps est écoulé, ce qui entraîne une égalité. Tout le reste en découle : le taux de victoires est mesuré ici, les valeurs attendues sont calculées ici et la réputation d'un véhicule se forge ici.
