term: Proximity spotting
aliases:

A regra de que qualquer veículo dentro de 50 metros é detectado independentemente do ocultamento, desde que exista linha de visão.

Dentro de 50 metros a camuflagem para de importar. Um veículo nesse raio é detectado assim que qualquer coisa consegue vê-lo, razão pela qual passar rapidamente por uma linha de arbustos revela tudo que está escondido nela.

Scouts usam isso de forma deliberada: uma passagem rápida por uma posição suspeita ilumina tudo nela para a equipe, ao custo de serem iluminados eles mesmos.
