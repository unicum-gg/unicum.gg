Урон, нанесённый союзником цели, которую игрок обнаружил или обездвижил сбитием гусеницы, засчитывается игроку, сделавшему этот выстрел возможным.

В игре учитываются два вида помощи. Помощь в обнаружении представляет собой урон, нанесённый машине, которую обнаружил игрок, а помощь в обездвиживании представляет собой урон, нанесённый машине, которую игрок обездвижил сбитием гусеницы. Оба вида учитываются полностью, поэтому за бой можно получить больше урона с помощью, чем нанесённого урона.

Именно урон с помощью позволяет оценивать эффективность лёгких танков. Главная задача разведчика состоит в том, чтобы сделать противника видимым для союзников, и без учёта урона с помощью эта работа не принесла бы результата. По этой причине для Отличительных отметок и некоторых рейтингов используется суммарный урон, то есть нанесённый урон плюс урон с помощью.

Урон за обнаружение цели засчитывается только одному игроку, который подсвечивает её в момент попадания, поэтому один и тот же урон с помощью не может быть учтён дважды в пределах команды.
