Какая доля игроков сервера фактически отслеживается сайтом статистики и насколько актуальны данные этих аккаунтов.

Ни один сервис статистики не охватывает все аккаунты. API Wargaming имеет ограничение на количество запросов, поэтому сервис находит аккаунты через составы кланов и поиск, а затем обновляет данные каждого из них с доступной ему периодичностью. Охват показывает, какая доля активных игроков региона есть в базе сервиса и как давно обновлялись данные каждого из них.

Это важно, потому что все рейтинги и средние показатели сервера рассчитываются по отслеживаемым игрокам, а не по всему серверу. Широкий охват делает эти показатели репрезентативными, а узкий охват превращает их в выборку.
