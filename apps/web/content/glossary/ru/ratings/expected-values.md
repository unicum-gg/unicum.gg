Средние серверные показатели для каждой машины, с которыми рейтинг сравнивает результаты игрока: то, чего обычно добивается средний игрок именно на этом танке.

Для каждого рейтинга по отдельным машинам нужна точка отсчёта. Ожидаемые значения и есть такая точка отсчёта: по одной строке на каждую машину со средними показателями урона, фрагов, засвета и защиты по серверу. Собственные показатели игрока делятся на эти значения, чтобы получить коэффициенты, используемые формулой рейтинга.

Таблицы поддерживаются сообществом, а не Wargaming, и периодически пересчитываются по большой выборке учётных записей. Между двумя выпусками состав машин продолжает меняться: для новых премиум и наградных машин ещё нет строки, поэтому рейтинг либо не учитывает их, либо использует среднее значение для сопоставимых машин того же уровня и класса.

Обновление набора данных незаметно меняет рейтинг каждого игрока. Если характеристики машины улучшили и средний урон на ней по серверу вырос, ожидаемое значение повышается, поэтому в следующий раз те же результаты дают более низкий рейтинг. Так и задумано: рейтинг сравнивает игрока с текущими показателями сервера, а не с зафиксированными в прошлом.
