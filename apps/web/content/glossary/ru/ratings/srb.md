Рейтинг Укрепрайона, в котором учитывается количество боёв, а не только их минимальное число, поэтому клан, доказавший своё мастерство в сотнях боёв, занимает более высокую позицию, чем клан с таким же SR после двадцати боёв.

SR намеренно не учитывает, сколько играет клан. SRB берёт тот же рейтинг и умножает его на коэффициент, который растёт вместе с количеством проведённых боёв, поэтому он всегда может быть только выше SR, на котором основан.

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

Зависимость логарифмическая, поэтому первые сто боёв дают гораздо больше, чем тысячный. ```

Для всех уровней намеренно используется одна и та же константа количества боёв: Вылазки на технике X уровня проходят постоянно, а Наступления проводятся периодами по несколько недель в году, поэтому уровни, на которых действительно играют больше, получают больший бонус. Та же идея используется для HRB рядом с HR в таблице «Стального охотника».
