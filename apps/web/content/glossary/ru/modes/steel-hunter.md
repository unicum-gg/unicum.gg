Режим «королевской битвы» на уменьшающейся карте со специальными улучшаемыми машинами, где занятое место не менее важно, чем нанесённый урон.

В Стальном охотнике игроки в одиночку или во взводах из двух человек высаживаются на большую карту на слабой версии одной из восьми специальных машин, по одной от каждой нации. Добыча и нанесённый урон позволяют во время боя улучшить её с ранга I до ранга VII, опасные зоны сокращают доступную область карты, а побеждает последний выживший.

**Статистики по нему не существует ни здесь, ни где-либо ещё.** Wargaming не публикует данные о Стальном охотнике ни в одном из своих открытых интерфейсов: режим отсутствует в статистике по аккаунтам, а для его восьми машин API показывает ноль боёв в каждой разбивке по режимам для отдельных машин, поэтому в этой статье есть числовые параметры правил режима, но нет показателей игроков. Невозможно составить рейтинг из ничего, а рейтинг, который этот сайт публиковал под этим названием до октября 2026 года, на самом деле целиком основывался на данных другого режима. См. «Бой до последнего».
