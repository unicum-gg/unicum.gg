Набор снарядов, которые орудие может выпустить один за другим до долгой перезарядки, лежащий в основе автоматов заряжания и механизмов дозарядки.

Орудие с барабаном вмещает сразу несколько снарядов. Оно выпускает их один за другим с интервалом лишь на внутрибарабанную перезарядку, после чего останавливается для полной перезарядки барабана, которая может длиться тридцать секунд и более.

Благодаря этому орудие наносит урон за короткий промежуток времени. Барабан на четыре снаряда с альфой 390 может снять 1,560 единиц прочности за десять секунд, чего достаточно, чтобы сразу уничтожить большинство противников, но после этого танк остаётся беззащитным.

Урон с барабана, то есть его суммарный урон, это показатель, который действительно важен при оценке того, можно ли пережить размен.
