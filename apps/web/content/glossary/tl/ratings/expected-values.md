Ang average na rating ng server bawat sasakyan ay sumusukat sa isang manlalaro: kung ano ang karaniwang nalilikha ng isang tipikal na manlalaro sa eksaktong tangke na iyon.

Bawat rating per-vehicle ay nangangailangan ng baseline. Ang expected values ay ang baseline na iyon, isang row para sa bawat sasakyan na nagbibigay ng average damage, frags, spotting at depensa na nalilikha ng server dito. Ang mga numero ng isang manlalaro ay hinahati sa mga ito upang makuha ang ratio na ginagamit ng rating formula.

Ang mga talahanayan ay pinapanatili ng komunidad, hindi ng Wargaming, at muling kinakalkula paminsan-minsan mula sa isang malaking sample ng mga account. Sa pagitan ng dalawang release, ang listahan ng sasakyan ay patuloy na nagbabago: ang mga bagong premium at reward vehicles ay walang row pa, kaya ang rating ay o tumatakbo nang wala sila o bumabalik sa average ng mga katulad na sasakyan sa parehong tier at klase.

Ang pag-update ng dataset ay tahimik na nag-a-adjust ng rating ng lahat. Kung ang isang sasakyan ay nabigyan ng buff at ang server ay nagsimulang gumawa ng mas maraming damage dito, ang inaasahan ay tumataas at ang parehong performance ay nagiging mas mababa sa susunod na pagkakataon. Ito ay nakaplano: ang rating ay sumusukat sa isang manlalaro laban sa kasalukuyang server, hindi laban sa isang naka-freeze na isa.
