Ang paglalaro ng isang sasakyan nang sadya upang maabot ang ikatlong Mark of Excellence, na nangangailangan ng pagpapanatili ng pinakamataas na limang porsyento na pinagsamang pinsala dito.

Ang isang three-mark run ay isang proyekto. Ang moving average sa likod ng mga marka ay nagbibigay ng gantimpala para sa konsistensya sa halip na mga spikes, kaya ang isang sesyon ng magagandang laban ay bahagyang nag-aangat ng porsyento at ang isang sesyon ng masamang laban ay bumabawi dito.

Binabago nito ang paraan ng paglalaro ng sasakyan: ang pinsala at tulong ay pinmaksimisa sa lahat ng ibang bagay, kabilang ang, kilalang-kilala, ang kinalabasan ng labanan, dahil ang mga marka ay hindi nagmamalasakit kung nanalo ang koponan.
