Isang pangalawang crosshair na nagpapakita kung saan iniisip ng server na nakaturo ang baril, na siya ring kung saan aktwal na binibigyan ng resulta ang litrato.

Agad na iguguhit ng client ang pagtarget na bilog, ang server ang nagtatakda kung saan pupunta ang bala. Ang pagkaantala sa network ay naglalagay sa dalawa na bahagyang magkahiwalay, at sa distansya ang agwat na iyon ay mas malawak kaysa sa isang mahina na bahagi.

Ang pag-on ng server reticle ay nagdadala ng awtoritatibong posisyon din. Ang mga manlalaro na umuukit ay nagpapaputok sa server crosshair sa halip na sa client na isa, na siyang dahilan kung bakit ito ay isang mod bago pa man ito naging setting.
