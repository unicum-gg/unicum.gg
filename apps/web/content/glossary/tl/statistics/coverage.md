Gaano karaming bahagi ng base ng manlalaro ng isang server ang tunay na tinutukoy ng isang stats site, at kung gaano ka-bago ang mga account na iyon.

Walang tracker na nakikita ang bawat account. Ang API ng Wargaming ay may limitasyon sa rate, kaya ang isang site ay nagtutuklas ng mga account sa pamamagitan ng mga listahan ng klan at mga paghahanap, pagkatapos ay ina-update ang bawat isa sa isang iskedyul na kayang ihandog. Ang coverage ay ang bahagi ng mga aktibong manlalaro sa rehiyon na hawak nito, at kung gaano ka-bago ang bawat na-update.

Mahalaga ito dahil ang bawat leaderboard at ang bawat average ng server ay kinakalkula batay sa mga tinukoy na populasyon, hindi sa buong server. Ang malawak na coverage ay ginagawang representante ang mga numerong iyon, habang ang manipis na coverage ay ginagawang sample lamang ang mga ito.
