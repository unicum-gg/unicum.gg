Δύο θέσεις που καλύπτουν την ίδια περιοχή από διαφορετικές γωνίες, έτσι ώστε ένα όχημα γωνιασμένο σε μία να είναι επίπεδο στην άλλη.

Η θωράκιση λειτουργεί μόνο σε μία κατεύθυνση τη φορά. Εναντίον ενός μόνο αντιπάλου, ένα όχημα μπορεί να γωνιαστεί, να πλευρίσει ή να πάει hull down, και εναντίον δύο που είναι ευρέως χωρισμένα, δεν μπορεί: ό,τι παρουσιάζει σε έναν είναι εκτεθειμένο στον άλλον.

Η δημιουργία μιας διασταυρούμενης φωτιάς είναι ο φθηνότερος τρόπος για μια ομάδα να νικήσει θωράκιση που δεν μπορεί να διεισδύσει από μπροστά, και το να μπαίνεις σε μία είναι το πώς ένα ισχυρό όχημα πεθαίνει χωρίς ποτέ να αναπα gespielt individually.
