Μια κασκανίνα όπλου που γεμίζει μία βολίδα τη φορά, έτσι ώστε να μπορεί να πυροβολήσει μία μόνο βολή και να συνεχίζει να γεμίζει στο παρασκήνιο.

Ένας autoreloader αντικαθιστά την κάψουλα όλων ή τίποτα με μία κυλιόμενη. Κάθε βολίδα γεμίζει ατομικά και οι βολίδες γεμίζουν πιο γρήγορα όταν η κασκά είναι πιο άδεια, έτσι ώστε το όχημα να μπορεί να πυροβολήσει μία φορά και να έχει τις υπόλοιπες βολές έτοιμες.

Παίζει σαν ένα κανονικό όπλο που μπορεί να εκτοξεύσει βολές κατ' απαίτηση. Η απόφαση που θέτει κάθε εμπλοκή είναι αν θα ξοδέψει την κασκά τώρα για έναν θάνατο ή αν θα κρατήσει τις βολίδες και θα παραμείνει απειλή.
