Η ξεχωριστή αξία ζημιάς που εφαρμόζει μια βολή σε modules και μέλη του πληρώματος, που είναι αυτό που αποφασίζει αν μια χτυπημένη βολή θα στήσει, θα σπάσει ή θα τραυματίσει.

Τα modules και το πλήρωμα έχουν τους δικούς τους πόντους ζωής και μια βολή φέρει τη δική της αξία ζημιάς απέναντί τους, συνήθως διαφορετική από τη ζημιά που προκαλεί στο ίδιο το όχημα. Μια χτυπημένη βολή που διεισδύει κοντά στον κινητήρα προκαλεί τη ζημιά του οχήματος και ξεχωριστά μειώνει την υγεία του κινητήρα.

Γι' αυτό, μια βολή που αποτυγχάνει να διεισδύσει μπορεί ακόμα να στήσει έναν στόχο: η πρόσκρουση εφαρμόζει ζημιά στα modules στους τροχούς ακόμα και όταν το θωρακισμένο σώμα δεν δέχεται τίποτα.
