Εμπειρία που μπορεί να δαπανηθεί σε οποιοδήποτε όχημα ή μονάδα, συσσωρεύεται ως μικρό ποσοστό όλης της εμπειρίας που αποκτάται και μπορεί να μετατραπεί από επίλεκτα οχήματα με χρυσό.

Ένα μικρό ποσοστό της εμπειρίας που αποκτάται σε κάθε μάχη κρατείται ως ελεύθερη εμπειρία. Δεν συνδέεται με συγκεκριμένο όχημα, οπότε μπορεί να δαπανηθεί για να παρακαμφθεί η βασική διαμόρφωση, να ξεκλειδωθεί απευθείας μια μονάδα ή να γίνει πρόοδος σε ένα δέντρο τεχνολογίας.

Η εμπειρία που βρίσκεται σε ένα επίλεκτο όχημα μπορεί επίσης να μετατραπεί σε ελεύθερη εμπειρία με χρυσό, επιτρέποντας στους παίκτες που έχουν ολοκληρώσει μια γραμμή να μετατρέψουν ένα αδρανές υπόλοιπο σε πρόοδο αλλού.
