Η εμπειρία που μπορεί να δαπανηθεί σε οποιοδήποτε όχημα ή μονάδα, συσσωρευμένη ως ένα μικρό ποσοστό από όλα όσα κερδίζονται και μετατρέψιμη από ελίτ οχήματα με χρυσό.

Ένα μικρό ποσοστό της εμπειρίας που αποκτάται σε κάθε μάχη κρατείται ως δωρεάν εμπειρία. Δεν συνδέεται με ένα όχημα, έτσι μπορεί να δαπανηθεί για να παρακαμφθεί μια βασική διαμόρφωση, να ξεκλειδώσει μια μονάδα άμεσα ή να προχωρήσει μπροστά σε ένα δέντρο.

Η εμπειρία που βρίσκεται σε ένα ελίτ όχημα μπορεί επίσης να μετατραπεί σε δωρεάν εμπειρία με χρυσό, που είναι ο τρόπος με τον οποίο οι παίκτες που έχουν ολοκληρώσει μια σειρά μετατρέπουν μια ανενεργή ισορροπία σε πρόοδο αλλού.
