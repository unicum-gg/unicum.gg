Ένα μπλοκ μαχών που παίχτηκαν σε μία καθιστική περίοδο, ανασυναρμολογημένο από έναν ανιχνευτή από τη διαφορά μεταξύ δύο στιγμιότυπων ενός λογαριασμού.

Η API της Wargaming εξυπηρετεί τα συνολικά στοιχεία ενός λογαριασμού, όχι τις μεμονωμένες μάχες του. Ένας ανιχνευτής καταγράφει τα συνολικά αυτά τακτικά και η διαφορά μεταξύ δύο στιγμιότυπων είναι ακριβώς οι μάχες που παίχτηκαν ανάμεσα τους, με τη ζημιά, τους θανάτους και τα αποτελέσματα τους.

Αυτή η διαφορά είναι μια συνεδρία. Είναι ο τρόπος που μια ιστοσελίδα μπορεί να δείξει τι έκανε ένας παίκτης σήμερα παρά ό,τι έχει κάνει από το 2013 και είναι αυτό πάνω στο οποίο υπολογίζονται οι πρόσφατες αξιολογήσεις.

Η ανάλυση της εξαρτάται από τη συχνότητα με την οποία καταγράφεται ο λογαριασμός, οπότε μια συνεδρία είναι ένα μπλοκ παιχνιδιού αντί για μία ακριβή αρχή και τέλος χρόνου και μια μάχη που παίχτηκε ακριβώς πριν από ένα στιγμιότυπο κατατάσσεται στην συνεδρία αυτού του στιγμιοτύπου.
