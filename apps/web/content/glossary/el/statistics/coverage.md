Πόσο μεγάλο κομμάτι της βάσης των παικτών ενός server παρακολουθεί πραγματικά μια ιστοσελίδα στατιστικών και πόσο φρέσκα είναι αυτά τα λογαριασμοί.

Καμία ιστοσελίδα παρακολούθησης δεν βλέπει κάθε λογαριασμό. Το API της Wargaming έχει περιορισμούς και έτσι μια ιστοσελίδα ανακαλύπτει λογαριασμούς μέσω καταλόγων κλασμάτων και αναζητήσεων και στη συνέχεια ανανεώνει κάθε λογαριασμό με μια περιοδικότητα που μπορεί να αντέξει. Η κάλυψη είναι το ποσοστό των ενεργών παικτών στην περιοχή που κατέχει και πόσο πρόσφατα ανανεώθηκε κάθε λογαριασμός.

Είναι σημαντικό διότι κάθε κατάταξη και κάθε μέσος όρος server υπολογίζεται πάνω στον παρακολούθηση πληθυσμό και όχι σε ολόκληρο τον server. Η ευρεία κάλυψη καθιστά αυτούς τους αριθμούς αντιπροσωπευτικούς ενώ η λεπτή κάλυψη τους καθιστά δείγμα.
