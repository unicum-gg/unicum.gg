Η Βαθμολογία Οχυρώσεων όπου επιβραβεύεται ο όγκος των μαχών αντί να αποτελεί απλώς προϋπόθεση, ώστε μια φυλή που έχει αποδείξει την αξία της σε εκατοντάδες μάχες να κατατάσσεται πάνω από μια φυλή με την ίδια SR σε είκοσι μάχες.

Η SR αγνοεί σκόπιμα πόσο συχνά παίζει μια φυλή. Η SRB παίρνει την ίδια βαθμολογία και την πολλαπλασιάζει με έναν όρο που αυξάνεται ανάλογα με τις μάχες στις οποίες βασίζεται, οπότε μπορεί μόνο να είναι υψηλότερη από την SR πάνω στην οποία υπολογίζεται.

```formula
SRB = SR x (1 + ln(1 + battles / 1000))

Λογαριθμικό, οπότε οι πρώτες εκατό μάχες αξίζουν πολύ περισσότερο από τη χιλιοστή. ```

Μία σταθερά όγκου για κάθε βαθμίδα, εσκεμμένα: η Αψιμαχία Βαθμίδας X παίζεται συνεχώς, ενώ οι Προωθήσεις διεξάγονται σε εξάρσεις για λίγες εβδομάδες τον χρόνο, οπότε οι βαθμίδες που πράγματι παίζονται περισσότερο κερδίζουν μεγαλύτερο μπόνους. Το μπόνους όγκου είναι αυτό που διαχωρίζει μια φυλή η οποία έχει διατηρήσει μια βαθμολογία σε εκατοντάδες μάχες από μια φυλή που την έφτασε σε είκοσι.
