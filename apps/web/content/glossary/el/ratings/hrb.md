Η αξιολόγηση Hunter κατά αγώνες είναι η Steel Hunter αξιολόγηση με όγκο μαχών που ανταμείβεται αντί να εκπίπτει, για τους παίκτες που συνεχίζουν να κερδίζουν σε έναν τρόπο που είναι δύσκολο να κερδηθεί.

Η HR εφαρμόζει μια έκπτωση όγκου, έτσι μια σύντομη τυχερή πορεία δεν μπορεί να κορυφώσει τον πίνακα. Η HRB αντικαθιστά αυτό το φρένο με έναν όρο που μεγαλώνει με τις μάχες που παίζονται, με τη λογική ότι μια πεντάδα στην κορυφή σε ένα battle royale είναι τόσο σπάνια ώστε να το κάνει συχνά είναι η επιτυχία.

Η HRB αναδιαρθρώνεται έτσι ώστε η διάμεση τιμή της να είναι κοντά στην HR, πράγμα που επιτρέπει στις δύο στήλες να κάθονται δίπλα-δίπλα και να διαβάζονται με τα ίδια χρώματα.
