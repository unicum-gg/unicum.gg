Τα γεγονότα που μπορεί να προκύψουν κατά τη διάρκεια μιας μάχης σε μερικούς χάρτες Τυχαίων Μαχών, αλλάζοντας το έδαφος που πλήττουν για το υπόλοιπο της.

Ένα αερόπλοιο κατεβαίνει πάνω από μια περιοχή, μια βομβιστική επίθεση επίπεδωσε μια γειτονιά, ένα τρένο εκτροχιάζεται κατά μήκος της διαδρομής του. Είναι μια ευκαιρία παρά μια σταθερά: δύο μάχες στον ίδιο χάρτη μπορούν να διεξαχθούν με και χωρίς ένα, γι' αυτό ο παιχνίδι λέει ότι ένα γεγονός *μπορεί* να συμβεί εδώ. Η περιοχή σημειώνεται πριν συμβεί, με καπνό στο χάρτη και ένα περίγραμμα στο μίνι χάρτη, και ένα όχημα που παγιδεύεται μέσα όταν προσγειωθεί το γεγονός μπορεί να καταστραφεί από αυτό. Μόλις περάσει, εκείνο το σημείο του χάρτη είναι διαφορετικό για το υπόλοιπο της μάχης: τα συντρίμμια κλείνουν μια διαδρομή, ένα καμένο αεροσκάφος γίνεται σκληρή κάλυψη, ένας κατεστραμμένος τοίχος ανοίγει μια διαδρομή που δεν υπήρχε στην αρχή.

Μόνο μερικοί χάρτες τις περιέχουν, και ένας χάρτης που τις περιέχει μπορεί να έχει περισσότερο από ένα. Είναι προαιρετικές: η καρτέλα Παιχνίδι των ρυθμίσεων έχει έναν διακόπτη που σας κρατά εκτός των χαρτών τυχαίων γεγονότων του matchmaking.

Είναι πιο σημαντικά για ένα σχέδιο από ό,τι υποδηλώνει το μέγεθός τους, ακριβώς επειδή είναι αβέβαια. Μια θέση που κρατά νωρίς δεν είναι η ίδια θέση αφού προσγειωθεί ένα γεγονός, και μια διαδρομή που εξαρτάται από μια επίθεση μπορεί να κλείσει κατά τη διάρκεια της, επομένως το έδαφος που αξίζει να δεσμευτεί είναι το έδαφος που επιβιώνει έτσι ή αλλιώς.
